# Sanjeev Rao Portfolio

React + Vite portfolio created from the supplied resume and profile photo.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Before deploying

1. Replace the `#` LinkedIn link in `src/App.jsx` with the real LinkedIn URL.
2. Confirm the GitHub URL.
3. Replace `public/profile.jpg` if you want to use a different photo.
4. Deploy to Vercel using the project root.

## Vercel

Build command: `npm run build`  
Output directory: `dist`
